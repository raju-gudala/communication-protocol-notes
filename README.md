# Communication Protocol Notes

Personal notes and reference material on communication protocols used in embedded systems and hardware design — covering theory, timing, wiring, and practical debugging tips.

## Why This Repo

A collection of notes built while working on embedded hardware and PCB design — meant as a quick reference for protocol fundamentals, common pitfalls, and things that aren't always obvious from a datasheet.


## What Each Note Covers

- **Overview** — what the protocol is and where it's used
- **Physical layer** — wiring, voltage levels, connector types
- **Timing & signaling** — clock behavior, framing, bit order
- **Common configurations** — typical speeds, modes, addressing
- **Debugging tips** — common issues and how to catch them
- **References** — datasheets, application notes, useful links
